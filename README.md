# 🎨 Etch-a-Sketch

A responsive and interactive **Etch-a-Sketch (Browser Drawing Pad)** built using **Vanilla HTML, CSS, and JavaScript**. This project demonstrates core web development concepts such as dynamic grid generation, DOM manipulation, event handling, and interactive UI design.

---

## ✨ Features

- 🔲 **Dynamic Grid Resizing**: Users can change the grid size (e.g., 16x16 up to 64x64 or 100x100) dynamically.
  over a square.
- 📱 **Responsive & Clean UI**: Center-aligned grid layout with a modern control panel.

---

## 🛠️ Tech Stack & Concepts

- **HTML5**: Structured semantic layout for the control panel and canvas container.
- **CSS3**:
  - CSS Grid / Flexbox for generating perfectly square grid cells.
  - Smooth hover transitions, borders, and clean UI styling.
- **JavaScript (ES6+)**:
  - **DOM Manipulation**: Dynamic creation (`createElement`), appending (`append`), and clearing (`innerHTML = ''`) of grid cells.
  - **Event Listeners**: Handling `click` events for seamless mouse drawing.
